# Echoes of Meridian

![Status: Em desenvolvimento](https://img.shields.io/badge/status-em%20desenvolvimento-yellow?style=for-the-badge)

Um platformer 2D de pixel art sobre Ester, uma técnica de manutenção presa em uma instalação científica abandonada. Após reativar um núcleo temporal, ela precisa usar ecos de suas próprias ações para resolver puzzles e interromper um ciclo de dez segundos.

## Sobre o jogo

Ester é uma técnica de manutenção enviada para investigar um sinal misterioso enviado de uma instalação científica abandonada. Ao reativar acidentalmente um núcleo temporal do Instituto Meridian, ela acaba presa em um ciclo que reinicia a cada dez segundos.

O núcleo registra as ações realizadas durante os dez segundos e as reproduz no ciclo seguinte como ecos. Para escapar, Ester precisa cooperar com suas próprias ações passadas e resolver os puzzles da instalação antes que o sistema se torne instável.

## Mecânicas principais

- Supere fases de plataforma com desafios baseados em ciclos temporais.
- Registre suas ações durante um ciclo de dez segundos e use os ecos para repeti-las no ciclo seguinte.
- Resolva puzzles com placas de pressão, barreiras e portas.
- Coordene diferentes ecos para realizar ações simultâneas.

## Tecnologia

- GameMaker
- GameMaker Language (GML)
- Resolução interna de 320 × 180
- Renderização pixel perfect

## Como executar

### 1. Clonar o repositório

Em seu terminal, vá até o diretório onde deseja clonar o repositório e execute:

```powershell
git clone https://github.com/devNicolasAmaral/eco-platformer-2d.git
cd eco-platformer-2d
```

### 2. Abrir no GameMaker

Para abrir o projeto, execute:

```powershell
"Eco - Platformer 2D.yyp"
```

### 3. Executar o jogo

No GameMaker, pressione `F6` ou use o botão Run na barra de ferramentas.
